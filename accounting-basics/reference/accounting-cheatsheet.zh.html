会计基础 — 一页速查表

整门课程的全部工具浓缩在一页可打印的纸上。打印出来，放在 10-K 手边。

三张报表

  • 利润表——我们赚钱了吗？（一个时段）
  • 现金流量表——现金去哪了？（同一时段的现金版本）
  • 资产负债表——我们有什么、欠什么？（某一天的快照：资产 = 负债 + 权益）

勾稽关系：净利润流入留存收益（减分红）；现金流量表的终点正是资产负债表那行现金。谎言必须在接缝处圆回来。

利润表阶梯

收入 → − 销货成本 → 毛利 → − 营业费用 → EBIT → − 利息 → − 税 → 净利润 → ÷ 摊薄股数 → EPS

资产负债表要点

  • 流动（≤ 1 年）vs 非流动——这条分界线定义了流动性。
  • 商誉警示：收购溢价形成的无形资产，可能一夜之间被一次性核销。
  • 递延收入是好负债：发货前先收到的现金——客户在预付给你钱。

现金流

  • 三大部分：经营活动、投资活动、筹资活动。
  • FCF = OCF − 资本开支。
  • 健康信号：OCF ≥ 净利润，且持续成立。

核心比率

比率公式读作
毛利率 (gross margin)毛利 / 收入定价权与生产成本
营业利润率 (operating margin)EBIT / 收入主业经营效率
净利率 (net margin)净利润 / 收入全口径盈利能力
净资产收益率 (ROE)净利润 / 权益股东资本的回报
杜邦分解 (DuPont)利润率 × 周转率 × 杠杆ROE 究竟由什么驱动
流动比率 (current ratio)流动资产 / 流动负债短期安全性（约 1.5–3 常见）
速动比率 (quick ratio)(流动资产 − 存货) / 流动负债不用变卖存货的流动性
负债权益比 (debt/equity)总债务 / 权益杠杆水平；同行业内比较
利息保障倍数 (interest coverage)EBIT / 利息费用债务还得起吗？（> 3 算舒适）
应收周转天数 (DSO)应收账款 / (收入 / 365)收回货款的天数；上升即警报

盈利质量检查

  • 净利润 vs OCF——持续的缺口是最经典的造假指纹。
  • 应计缺口 = 净利润 − OCF；大且为正 = 盈利脆弱。
  • 应收账款（和存货）增速远超收入。
  • 连续"一次性"项目——年年都有的就不叫一次性，叫经营成本。
  • GAAP 与非 GAAP 的差距——桥搭得越长，越是有人在卖力推销。

红旗清单（第 7 课）

  1. 应收账款增速 ≫ 收入增速
  2. DSO 持续上升
  3. 存货增速超过收入
  4. OCF 长期低于净利润
  5. 连续"一次性"费用
  6. GAAP 与非 GAAP 差距悬殊
  7. 治理信号：更换审计师、CFO 频繁离职、关联交易、财务重述
