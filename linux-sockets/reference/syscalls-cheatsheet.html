Syscall Cheat Sheet

The TCP client/server dance, the structs, the byte-order rules, the errnos, the socket options, the debug commands — one page.

The sequence

ServerClientWhat the kernel does
s = socket(AF_INET, SOCK_STREAM, 0)fd = socket(...)Allocates the endpoint; returns an fd. No address yet.
bind(s, &addr, len)—（usually skipped）Pins fd to local IP:port. Client gets an ephemeral port at connect.
listen(s, backlog)—Marks passive; allocates SYN queue + accept queue.
c = accept(s, ...) blocksconnect(fd, &srv, len)Three-way handshake; accept pops it and returns a NEW fd for that peer.
read(c, buf, n) / write(c, buf, n)write / readDrain/fill per-socket kernel queues. No message boundaries.
close(c)（keep s）close(fd)Friendly disconnect: FIN, then the teardown state machine (FIN_WAIT / TIME_WAIT…).

Errnos worth memorizing

errnoFromMeaning
EADDRINUSEbindPort taken (or a TIME_WAIT remnant — fix with SO_REUSEADDR, set before bind).
ECONNREFUSEDconnectNothing listening at that IP:port (RST came back).
EPIPEwritePeer already closed (and you ignored read's 0 / ECONNRESET).
EAGAINread/writeNon-blocking socket, nothing ready right now — not an error.
EINTRmostA signal interrupted the call — just retry it.

Socket options that matter first

OptionWhy you set it
SO_REUSEADDRLets a server rebind its port immediately after restart (TIME_WAIT survival). Level SOL_SOCKET, before bind.
TCP_NODELAYDisables Nagle's algorithm — small request/response latency.
SO_KEEPALIVEKernel probes a silent connection; detects dead peers eventually.
