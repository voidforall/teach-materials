调用时序

服务端客户端内核在做什么
s = socket(AF_INET, SOCK_STREAM, 0)fd = socket(...)分配端点，返回 fd。此时还没有地址。
bind(s, &addr, len)—（通常跳过）把 fd 绑定到本地 IP:端口。客户端的临时端口由 connect 时分配。
listen(s, backlog)—转为被动；分配 SYN 队列 + accept 队列。
c = accept(s, ...) 阻塞connect(fd, &srv, len)三次握手；accept 弹出完成的连接，返回一个专属新 fd。
read(c, buf, n) / write(c, buf, n)write / read倾倒/填充每 socket 的内核队列。没有消息边界。
close(c)（保留 s）close(fd)友好断开：FIN，随后进入拆除状态机（FIN_WAIT / TIME_WAIT…）。

地址结构体与字节序

对象写法要点
IPv4 端点struct sockaddr_in {sin_family, sin_port, sin_addr}传入时强转 (struct sockaddr *)；那个类型只是通用的"字节袋"视图。
任意本地地址addr.sin_addr.s_addr = htonl(INADDR_ANY)即 0.0.0.0 —— 在所有网卡上接受连接。
端口 / IP 上线路htons() / htonl()网络序是大端；主机序未必。还原用 ntohs/ntohl。
字符串 ⇄ 地址inet_pton() / inet_ntop()取代已废弃的 inet_addr 一族。
域名 → 端点（可移植）getaddrinfo()解析主机+服务名，替你填结构体，天然支持 IPv6。优于 gethostbyname。

值得背下来的 errno

errno出自含义
EADDRINUSEbind端口被占（或 TIME_WAIT 残留 —— 用 SO_REUSEADDR 解决，须在 bind 之前设置）。
ECONNREFUSEDconnect该 IP:端口没有监听者（对方回了 RST）。
EPIPEwrite对端早已关闭（而你忽略了 read 的 0 / ECONNRESET）。
EAGAINread/write非阻塞 socket 此刻无数据 —— 不算错误。
EINTR多数调用被信号打断 —— 重试即可。

最先用得上的 socket 选项

选项为什么设它
SO_REUSEADDR让服务端重启后立即重新绑定端口（躲开 TIME_WAIT）。SOL_SOCKET 层级，bind 之前设。
TCP_NODELAY关闭 Nagle 算法 —— 降低小请求/响应的延迟。
SO_KEEPALIVE内核主动探测静默连接；最终能发现死掉的对端。

用内核的视角看（调试命令）

命令能看到什么
ss -tlnp / lsof -i :端口监听中的 socket 及属主进程；已建立的连接对。
strace -e trace=network ./server你的程序真实发出的每一条 socket 系统调用。
tcpdump -i lo port 5000数据包本身：SYN、ACK、FIN、RST、载荷。
nc 主机 端口 / nc -l 端口即时客户端 / 即时一次性服务器。
