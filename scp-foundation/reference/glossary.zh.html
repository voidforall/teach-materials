词汇表与 Object Classes

压缩版参考。术语只在这一处定义 —— 每课都以此为准。

Object Classes（项目等级）

等级 = 收容难度，绝不是危险度。来源：Object Classes 文章。

主要等级

Safe
适度投入即可可靠收容。常在被触发前 inert（惰性）。"致命但 Safe"很常见。
Euclid
收容得住但不可靠；理解不全或不可预测。自主 / 活着 / 有智能的默认归此。
Keter
极难收容；程序繁复、易突破。不是"邪恶"的同义词。
Thaumiel
被基金会拿来收容其他异常。存在本身高度机密（仅 O5）。

次要与升级等级

Apollyon
无法收容 / 突破在即 / 世界终结。"末日已至"级。
Archon
理论上可收容，但被刻意不收 —— 收容它危害更大。
Cernunnos
功能上可收容，但基金会选择不收（后勤/伦理原因）。
Ticonderoga
不可收容但无需收容 —— 遍布地球或不在地球。

处置状态（是状态，不是难度）

Neutralized
不再异常 —— 被毁、失效或性质停止（未必是刻意的）。
Decommissioned
被基金会刻意摧毁/剥夺异常。与 Neutralized 的差别就在意图。
Explained
后来发现是寻常科学、骗局或误会。
Pending / Uncontained
尚未分级（数据不足）/ 尚未收容（努力进行中）。
Esoteric
故事专用的一次性等级。仅当在 25+ 篇文章复用才获官方承认。

核心词表

The Foundation（基金会） — 秘密组织，Secure（控制）、Contain（收容）、Protect（保护）异常以维持常态。

SCP-#### — 一个异常物体、实体或现象，引申为记录它的文章。编号大致按时间、不按排名。

Containment Procedures（收容程序） — "我们怎么把它留在盒子里"的部分；通常是文章的第一段。

O5 Council — 十三位最高权限监察者。最大权限；身份保密。

MTF — Mobile Task Force（机动特遣队）：派去回收或再收容异常的专家队伍（如 MTF Epsilon-11 "Nine-Tailed Fox"）。

GoI — Group of Interest（相关组织）：任何涉足超自然世界的组织（公司、邪教、政府、团体）。按它要异常为了什么归档。

Special Containment Procedures（特殊收容程序） — "我们怎么把它留在盒子里"的部分；排在 Description 之前以制造恐惧。绝不该被涂黑。见第 3 课。

Description（描述） — 异常到底是什么；从平常开始、转向异常。在程序之后的揭晓。

Addendum（附录） — 主档案之后的附加材料（实验记录、访谈、更新）；叙事弧光/反转通常住在这里。

Clinical tone（临床语调） — 所有文章共用的扁平科学报告腔。不动声色的声音与骇人内容之间的落差是核心恐惧装置。

ACS — Anomaly Classification System：较新的可选"危险钻石"栏，在传统等级旁附加更细的风险/收容评级。

Redaction / [DATA EXPUNGED]（涂黑/数据删除） — 刻意隐藏的文字。恐怖住在空白里，由读者的想象去填。核心风格装置。

Tale（故事） — 设定宇宙中的叙事小说，无临床档案格式。有人物与情节。见 Tales Hub。

Canon（正典） — 多位作者以内部自洽方式共建、自愿加入的策展共享宇宙。见 Canon Hub 与第 5 课。

"There is no canon"（没有正典） — 本站的立站原则。不是零正典，而是一大堆交叠的正典；没有唯一"真传"。文章矛盾时谁都没错。问作者在做什么，别问哪个是真的。

Series（系列） — SCP 编号按 1000 一组划分（Series I = 001–999，II = 1000–1999……）。按时间、不按质量 —— 低编号最老。

Top Rated Pages（高分页） — 社区点赞的最佳榜；寻找杰作的推荐正门，别按编号读。

SCP-001 — 一个保留位，装着多份相互竞争的"提案（proposals）"（不同作者对第一个异常的演绎）。晦涩；不是新手起点。

Groups of Interest（按动机）

动机 → 对基金会的立场。来源：GoI hub。见第 2 课。

Chaos Insurgency
权力。立志摧毁基金会的前叛逃者 —— 镜像之敌。
Global Occult Coalition
干净的世界。隶属联合国、摧毁异常的超自然警察 —— 竞争同行。
Church of the Broken God
神圣的机械。重建机械之神的金属宗教 —— 敌对。（与 Sarkic 成对。）
Sarkic Cults (Nälkä)
血肉的主宰。有机改造的食人邪教 —— 敌对，具 XK 级威胁。（血肉对教会的金属。）
Marshall, Carter & Dark
利润。向超级富豪出售异常的经纪 —— 非道德对手。
Are We Cool Yet?
被看见。制造致命异常艺术的"anartists" —— 反帷幕、混沌。
The Serpent's Hand
解放。把有感知的异常放出收容 —— 道德反驳者。
