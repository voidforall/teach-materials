一篇 SCP 的解剖

每篇文章共享的骨架 —— 以及为什么它的顺序是一台让你害怕的机器。

第 1、2 课给了你等级透镜和世界的演员表。现在是单篇文章本身。每份 SCP 档案都长着同一副骨架 —— 一旦你能摸到这副骨架，你就不再被动阅读，而是开始注意到恐怖是在哪里被工程出来的。

五块骨头，自上而下

标准结构，从上到下：1

1 · ITEM #
编号 —— SCP-173。一个冷冰冰的目录号。在恐怖开场前先把它去个人化。
2 · OBJECT CLASS
Safe / Euclid / Keter…… —— 收容难度读法。一个词就设定好你的威胁预期。
3 · SPECIAL CONTAINMENT PROCEDURES
怎么把它留在盒子里。出现在你甚至还不认识"它"之前。
4 · DESCRIPTION
它到底是什么 —— 从正常开始，然后转向异常。揭晓。
5 · ADDENDA
实验记录、访谈、事故报告。可选 —— 而故事通常就藏在这里。
关键思想 收容程序排在描述之前，是刻意的。你在被告知"为什么"之前，先读到一串离奇的预防措施 —— 而你的想象会用比任何解释都更糟的东西填满那个空隙。1

为什么这个顺序是一台恐惧引擎

这个技巧你早就体会过，只是没给它起过名字。想想 SCP-173 的程序：收容间内必须两人同在、绝不中断视线、轮流眨眼。还没人告诉你 173 会做什么 —— 但这些规则已经让你后颈发麻。预防措施暗示了威胁。机器就是这个。

官方指南把机制说得很直白：收容程序部分"引人入胜地引入异常……在揭示细节之前制造读者预期"。1等 Description 出来解释时，你的恐惧已经建好了。

临床语调对比机

每篇文章都用平铺直叙的公文体写作 —— "类似科学论文或政府报告的语言"，无第一人称、无口语。1这不是偷懒的写作。它是核心装置：

吓人的是落差 用不动声色的、程序化的声音描述的恐怖，比戏剧化描述的更可怕。语调越冷，怎么说与在说什么之间的落差越大 —— 惶恐就住在那个落差里。

当一份报告用规定门板钢材规格的同一副腔调，平静地记下某人员"随后被还原为有机浆液"时，那股平淡本身就是恐怖。读的时候去感受这个落差 —— 它是刻意的。

Redaction（删除）：空白里的恐怖

著名的 ████、[REDACTED] 和 [DATA EXPUNGED]。读者的本能是觉得被骗了 —— 他们把精彩的部分藏起来了。翻转它：空白是一份邀请。你脑补出的任何东西都比纸上的文字更吓人，而作者一个字都不用花。

读者秘技 —— 分辨好手艺与坏仿品 Redaction 属于 Description 和 addenda，绝不该出现在收容程序里。指南说得明白：程序里的信息不应该被藏 —— "隐匿其中部分是危险的"，因为工作人员必须知道怎么收容这东西。1程序被涂黑通常是劣质仿味文章的标志。涂掉结果才是真功夫。

"少即是多" —— 克制原则

wiki 自己的建议：只保留"必要的元素"；若某个细节"不能改善阅读体验，就删掉或一笔带过"。1最好的 SCP 解释得比它能解释的更少。一个只被理解一半的异常，比一个被完整归档的更可怕。当你注意到一篇杰作故意留下未解之处 —— 那不是漏洞。那是手艺。

你的新阅读清单

  1. 先读程序并问"他们为什么需要那样做？" —— 让惶恐在 Description 解答之前先涨起来。
  2. 感受语调与内容的落差。声音越平、事件越糟，写作越好。
  3. 把每一处涂黑当作邀请，不是省略。自己来填那个空。
  4. 期待 addenda 里的回报。实验记录与访谈通常藏着弧光与反转。

试一试 —— 回忆，别偷看

1. 收容程序为什么排在 Description 之前？

预防措施在解释之前暗示了威胁。

想象去填空 —— 恐惧被提前建好。

2. 临床语调为什么吓人而不是无聊？

平淡的声音与可怕的内容之间的落差。

冷着 deliver 恐怖，胜过戏剧化地。

3. 哪个部分不该出现 redaction，为什么？

程序 —— 员工必须知道怎么收容。

藏起收容步骤很危险；要涂就涂结果。

4. 杰作把异常解释一半。瑕疵还是手艺？

手艺 —— 克制让未知更可怕。

"少即是多"：只解释必要的，其余靠暗示。

首选材料 —— 接下来读这个 How To Write An SCP —— 写给作者的，但对读者而言是给这副骨架拍的最佳 X 光片。略读收容程序与临床语调两节，然后拿着清单重读 SCP-173，看这台机器运转。
问你的老师。 想看这份清单逐行套用到某篇具体文章上？好奇"Clinical Tone Declassified"或者人形/访谈怎么写？还是准备好上第 4 课 —— 在一万多篇的 wiki 里找到真正的杰作？说一声。
