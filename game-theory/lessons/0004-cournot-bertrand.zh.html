市场博弈：Cournot 与 Bertrand

真实公司不是从两个格子里挑 —— 它们挑一个数。best response 变成函数，均衡就是两条曲线的交点。

到目前为止的博弈都是小网格行动。但公司的一步棋是一个数量或一个价格 —— 连续的数。整套工具仍然成立；只是两样东西升级：best response 变成 reaction function（反应函数），Nash equilibrium 变成两条反应函数相交的点。本课在两个主力竞争模型上把它做实 —— 结尾还有一记电击：同样两家公司，可以赚得盆满钵满，也可以赚零，差别只在它们竞争的是数量还是价格。

Cournot：公司选数量

两家公司生产同质品，各选产量 q₁ 和 q₂。总产量 Q = q₁ + q₂ 越大，市场出清价越低：

价格 P = a − Q = a − q₁ − q₂；单位成本为 c。

公司 1 的利润是收入减成本：π₁ = (P − c)·q₁ = (a − c − q₁ − q₂)·q₁。现在找公司 1 的 best response —— 在给定 q₂ 下最大化 π₁ 的那个 q₁。对 q₁ 求导并置零（利润山的山顶）：1

a − c − 2q₁ − q₂ = 0  ⟹  q₁ = (a − c − q₂) / 2

Reaction function（反应函数） 最后这行就是公司 1 的反应（best-response）函数："不管你产多少，我产剩下市场的一半。"对手产得越多，我产得越少 —— 曲线向下倾斜。公司 2 的是镜像。Nash equilibrium 是同时落在两条曲线上的唯一一组 (q₁, q₂)。

曲线在哪里相交

取整数：a = 12、c = 0。公司 1：q₁ = (12 − q₂)/2。公司 2：q₂ = (12 − q₁)/2。由对称性设 q₁ = q₂ = q：q = (12 − q)/2 ⟹ 3q = 12 ⟹ q = 4。

每家的 best-response 曲线都向下倾斜；交点只有一个 —— Cournot 均衡。

读出结果：总产量 Q = 8，价格 P = 12 − 8 = 4，各赚 (4 − 0)·4 = 16。对比两个极端：

  • 像垄断者一样合谋（共同限产）：总产量 Q = 6、价格 6、对分 36 → 各 18 —— 对它们更好，对买家更糟。
  • 完全竞争：价格被压到成本 0。

Cournot 落在中间：竞争侵蚀垄断利润（16 < 18）但没有抹掉它。公司越多，均衡越滑向竞争价格 —— 本模型的招牌结论。

Bertrand：公司选价格 —— 以及悖论

同样的两家公司、同样的常数成本 c、同质品。但现在它们挂价格，所有买家都去便宜的那家。对手定价 p，你的 best response 是什么？

压他一分 —— 定价比 p 低一丁点、独吞整个市场，只要还高于成本 c。但对手的推理一模一样。于是互相压价、没完没了……

Bertrand 悖论 ……直到价格碰到边际成本 c，谁也无法再有利可图地降价。唯一均衡是 p₁ = p₂ = c，利润为零。仅仅两家定价公司就复现了完全竞争的结果。与 Cournot 里的同两家公司（各赚 16）相比，这里颗粒无收。你竞争的战略变量（数量 vs 价格）可能比竞争者人数更要紧。

这确实惊人，而它的"解法"正是真实市场的所在 —— 每一条都放松一个假设：

  • 产能限制 —— 你其实吃不下整个市场，就没法真正压死对手（这连回第 3 课的 commitment —— 产能是一个可信的先手）。
  • 产品差异化 —— 若产品不同质，便宜一点的对手偷不走你全部买家；价格停在成本之上。
  • 重复 —— 反复相遇的公司可以用"惩罚降价"的威胁维持高价（下一课的地盘）。

自测

Q1. 连续行动下，Nash equilibrium 在几何上是什么？

双方反应曲线同时相交的那个点。

与双划线同一思想：同时互为 best response。

Q2. 为什么两家 Bertrand 公司最终定价在边际成本？

谁都能靠压价独吞市场，直到再压就无利可图。

任何高于成本的价格都邀请对手便宜一分钱、拿走一切。

Q3. （间隔回忆 —— 第 3 课）为什么"我们打价格战"的威胁不总能吓退进入？

若开战也伤在位者自己，威胁不可信、会被无视。

Backward induction 只保留行动者真的会执行的威胁。

试一试 —— 展开前先推导均衡

两家公司进行 Cournot 竞争。需求为 P = 8 − Q（Q = q₁ + q₂），单位成本 c = 2。求公司 1 的反应函数与对称均衡下每家的产量。

展开解答

反应函数：q₁ = (6 − q₂)/2。均衡：各产 q₁ = q₂ = 2。

利润 π₁ = (8 − q₁ − q₂ − 2)·q₁ = (6 − q₁ − q₂)·q₁。对 q₁ 求导置零：6 − 2q₁ − q₂ = 0 ⟹ q₁ = (6 − q₂)/2 —— 与例题同形，只是 (a − c) = 6。对称：q = (6 − q)/2 ⟹ 3q = 6 ⟹ q = 2。于是 Q = 4、价格 P = 8 − 4 = 4，各赚 (4 − 2)·2 = 4。检验：垄断者会定 Q = (a−c)/2 = 3（价格 5、利润 9）—— 多于双寡头对分的 4 + 4 = 8，正合预期：竞争压低价格、也压小每家的份额。
