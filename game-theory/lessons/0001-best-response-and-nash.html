Best Response & the Underline Method

One mechanical procedure that finds every pure-strategy Nash equilibrium in any payoff matrix — no guessing.

You already know the phrase "Nash equilibrium." This lesson turns it into a skill you can execute: given any two-player matrix, you'll find all its pure equilibria by hand in under a minute. That's the load-bearing move for everything ahead — pricing wars, entry decisions, auctions.

The one idea underneath everything: best response

A game is any situation where your best move depends on what others do. So freeze the others for a moment and ask the only question that matters:

"If they do that, what's the best I can do?" — that answer is your best response.1 Everything in game theory is players best-responding to each other. Solve a game = find where all the best responses agree at once.

How to read a payoff matrix

The normal form lays a game out as a grid. Rows are one player's actions, columns the other's. Each cell holds a pair of payoffs. Convention: the row player's payoff is written first. Higher is better.

How to read one cell — (row's payoff, column's payoff)
Rival: LeftRival: Right
You: Up(3, 1)(0, 0)
You: Down(2, 2)(1, 4)

Blue = the row player ("You") · Red = the column player ("Rival")

The underline method

This is the whole procedure. Four passes, then read off the answer:

  1. Fix each column (a choice by the Rival). In that column, find your best payoff and underline it in blue. That's your best response to that column.
  2. Repeat for every column.
  3. Fix each row (a choice by You). In that row, find the Rival's best payoff and underline it in red.
  4. Repeat for every row.
Keystone Any cell where both numbers are underlined is a pure-strategy Nash equilibrium: each player is already best-responding to the other, so neither wants to move. Zero double-underlines → no pure NE. Several → several equilibria.

Worked example 1 — a price war

Two coffee shops each set a price, High or Low. Both High is cozy for everyone; if you undercut a High rival you steal their customers; if both go Low you're stuck in a margin war.

Shop A (rows) vs. Shop B (columns) — payoffs = profit
B: HighB: Low
A: High(3, 3)(1, 4)
A: Low(4, 1)(2, 2)

Blue passes (A's best response): if B plays High, A compares 3 vs 4 → Low (4). If B plays Low, A compares 1 vs 2 → Low (2). A prefers Low whichever column — Low is a dominant strategy for A.

Red passes (B's best response): by symmetry, B underlines Low in both rows.

The only double-underlined cell is (Low, Low) = (2, 2) — the unique Nash equilibrium. Notice the sting: both would earn 3 under (High, High), but each can't resist undercutting, so competition drags them to 2 apiece. That's the Prisoner's Dilemma hiding inside every price war.2

Worked example 2 — a standards war (two equilibria)

Dominance won't always hand you the answer. Two firms each adopt a file format, A or B. They only make money if they match the rest of the market; format B is the better technology, so matching on B pays more than matching on A.

Firm 1 (rows) vs. Firm 2 (columns) — coordination payoffs
Firm 2: AFirm 2: B
Firm 1: A(2, 2)(0, 0)
Firm 1: B(0, 0)(3, 3)

Run the passes: if Firm 2 picks A, Firm 1's best reply is A (2 > 0); if Firm 2 picks B, Firm 1's best reply is B (3 > 0). Neither action is dominant — the right move depends on the rival. Two cells end up double-underlined: (A, A) and (B, B).

What this teaches A game can have more than one Nash equilibrium. Both (A,A) and (B,B) are self-enforcing, but (B,B) pays everyone more. Game theory tells you both are stable resting points; it does not promise you land on the best one. Escaping a stuck-on-A market is a coordination problem — the seed of standards battles, network effects, and lock-in.

Check yourself

Q1. In your own words, when is a cell a Nash equilibrium?

When each player is best-responding to the other, so neither can gain by changing alone.

Operationally: both payoffs in that cell are underlined by the method.

Q2. A game has zero double-underlined cells. What does that mean?

It has no equilibrium in pure strategies; a stable solution needs randomizing.

"Mixed" strategies come next lesson — Nash proved one always exists once you allow them.

Q3. Why do the two shops earn 2 each instead of 3 each?

Each has a dominant Low, so mutual best-responding lands below joint-best.

Individual rationality and collective good pull apart — the core tension of the field.

Now you drive

Try it — before you reveal

You (rows) face a Rival (columns). Run the four passes on paper. Hint: the Rival has a dominant strategy — find it first, then best-respond to it. How many Nash equilibria are there, and which cell?

Rival: LeftRival: Right
You: Up(2, 1)(0, 2)
You: Down(1, 0)(1, 3)
Reveal the solution

One equilibrium: (Down, Right) = (1, 3).

Rival (red): Right beats Left in both rows — top row 2>1, bottom row 3>0 — so Right is dominant; underline Right's payoff in both rows. You (blue): if Rival plays Left you'd pick Up (2>1), but a rational Rival won't play Left. Against the Rival's actual choice, Right, you compare Up=0 vs Down=1 → Down. Only (Down, Right) is double-underlined. Note the twist: you'd love the (Up, Left)=2 cell, but it isn't an equilibrium — the Rival would bolt to Right, so it can't hold.
