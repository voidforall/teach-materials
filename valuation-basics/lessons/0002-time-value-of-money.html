Time Value of Money

A dollar next year is worth less than a dollar today. Every valuation formula in this course is one of four building blocks stacked on that fact. Learn the four blocks once, recognize them forever.

Cash arrives at dates; value must be stated today. Moving money across time uses a discount rate r (per period). The four primitives from Damodaran's Session 2:

  1. Present value of a lump sum: PV = CFn / (1+r)n. One payment, n periods away.
  2. Present value of an annuity: PV = CF × [1 − (1+r)−n] / r. Same payment each period for n periods.
  3. Growing annuity: PV = CF1/(r−g) × [1 − ((1+g)/(1+r))n]. Payments grow at g for n periods. This is the engine of an explicit forecast window.
  4. Growing perpetuity: PV = CF1 / (r−g), valid only when g < r. This is the engine of the terminal value — Lesson 8.

Notice the shape: a DCF is nothing but a growing annuity (the forecast years) plus a growing perpetuity (everything after). The entire machinery of corporate valuation fits in one line:

Value = Σ  E(CF_t) / (1+r)^t      for t = 1..n      (the story years)
      + Terminal value / (1+r)^n                   (the rest, forever)

Compounding intuition

Discounting is just compounding run backwards. At r = 10%: $1 in a year is worth 1/1.10 = $0.909 today; $1 in ten years is worth $0.386. Small changes in r compound brutally over long horizons — which is why the terminal value (far cash flows) is where discount-rate mistakes hurt most, and why estimates of r deserve as much care as estimates of growth.

Keystone All of DCF is four TVM blocks. Lump sum, annuity, growing annuity, growing perpetuity. When a valuation formula intimidates you, decompose it — you will find these four underneath, wearing a suit.
Anti-pattern Nominal rates with real cash flows. Discount nominal cash flows with nominal rates, or real with real — never mix. A 6% nominal rate against 2%-inflation-adjusted cash flows silently poisons every present value. Damodaran flags this as the most common mechanical error in student DCFs.

Retrieve it

Perpetuity: CF = $100, r = 8%, g = 3%. Value today?

$100 / 0.05 = $2,000.

Growing perpetuity: CF₁/(r−g) = 100/(0.08−0.03). Note the formula uses next period's cash flow — a classic off-by-one error is discounting this year's.

What happens if you assume g > r forever?

Value becomes infinite.

A cash flow growing faster than the discount rate forever exceeds the economy itself. This is the sanity check that kills fantasy terminal values — no company outgrows the world in perpetuity.

Which two TVM blocks compose a standard DCF?

Growing annuity plus perpetuity.

Explicit forecast window = growing (or staged) annuity; terminal value = growing perpetuity discounted back n periods. Everything else is bookkeeping.

Prove it to yourself

Try it — 15 minutes, calculator only Value this imaginary firm: cash flow to owners next year $100, growing 5%/yr for 5 years, then 2% forever; discount rate 9%. (a) Discount each of the 5 cash flows by hand. (b) Compute the terminal value at year 5: TV = 100×1.05⁵×1.02/(0.09−0.02). (c) Discount the TV back and add. You should get ≈ $1,835 total. You have just built a complete DCF — the next eight lessons only refine its inputs.
