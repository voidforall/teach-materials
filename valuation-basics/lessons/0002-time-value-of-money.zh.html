货币时间价值

明年的 1 美元比今天的 1 美元便宜。本课程的每一个估值公式，都是四个基本积木在这一事实上的堆叠。学一次这四块积木，就能永远认出它们。

现金发生在具体时点，而价值必须以今天表述。跨期移动货币需要一个折现率 r（每期）。以下是 Damodaran 第 2 讲的四个原语：

  1. 一次性款项的现值：PV = CFn / (1+r)n。一笔 n 期之后的付款。
  2. 年金的现值：PV = CF × [1 − (1+r)−n] / r。每期等额，共 n 期。
  3. 增长年金：PV = CF1/(r−g) × [1 − ((1+g)/(1+r))n]。付款按 g 增长 n 期。这是显性预测期的引擎。
  4. 增长永续：PV = CF1 / (r−g)，仅当 g < r 时有效。这是终值的引擎——第 8 课。

注意这个形状：DCF 无非是一个增长年金（预测年份）加一个增长永续（之后的一切）。整个公司估值机器就一行：

价值 = Σ  E(CF_t) / (1+r)^t      t = 1..n      (讲故事的年份)
      + 终值 / (1+r)^n                         (之后的所有永远)

复利的直觉

折现就是把复利倒着放。r = 10% 时：一年后的 1 美元今天值 1/1.10 = 0.909 美元；十年后的 1 美元只值 0.386 美元。r 的小变化在长期限上会造成残酷的复利差异——这正是为什么终值（遥远的现金流）对折现率误差最敏感，也为什么对 r 的估计应该和增长估计同样用心。

关键点 整个 DCF 就是四个 TVM 积木。一次性款项、年金、增长年金、增长永续。当某个估值公式吓到你时，把它拆开——底下一定是这四块穿着西装。
反面模式 名义利率配实际现金流。名义现金流配名义利率，或实际配实际——绝不混用。用 6% 的名义利率去折按 2% 通胀调整过的现金流，会悄无声息地毒化每一个现值。Damodaran 把这列为学生 DCF 中最常见的机械错误。

回忆检索

永续：CF = 100 美元，r = 8%，g = 3%。今天的价值？

100 / 0.05 = 2,000 美元。

增长永续：CF₁/(r−g) = 100/(0.08−0.03)。注意公式用的是下一期的现金流——把今年的现金流代进去是经典的差一期错误。

如果假设 g 永远大于 r 会怎样？

价值变成无穷大。

永远跑赢折现率的现金流最终会超过整个经济体。这条常识检验专杀幻想终值——没有公司能永远跑赢全世界。

标准 DCF 由哪两个 TVM 积木组成？

增长年金加永续。

显性预测期 = 增长（或分段）年金；终值 = 折回 n 期的增长永续。其余全是簿记。

亲手验证

试一试 —— 15 分钟，只要计算器 给这家虚构公司估值：明年归属股东的现金流 100 美元，前 5 年每年增长 5%，之后永远增长 2%；折现率 9%。(a) 手工折现 5 笔现金流。(b) 计算第 5 年末终值：TV = 100×1.05⁵×1.02/(0.09−0.02)。(c) 把终值折回并求和。总价值应约 1,835 美元。你刚刚做了一个完整的 DCF——后面八节课只是精修它的输入。
