# 0001 — Course published: Valuation Basics (Damodaran)

## Context
User requested a full bilingual (EN/ZH) course on valuation basics, sourced from Aswath Damodaran (NYU Stern), delivered in one uninterrupted session.

## What was built
- 10 lessons × 2 languages: price vs value → TVM → DCF skeleton → FCFF/FCFE → risk-free & ERP → beta/WACC → growth=reinvestment×ROIC → terminal value → multiples → capstone with bias audit.
- Reference cheat sheet (EN + ZH); shared stylesheet reused from harness-engineering.
- All citations point at pages.stern.nyu.edu, the class webcasts, the free Little Book/Investment Valuation PDFs, and Musings on Markets.

## Non-obvious decisions
- Standardized on the firm DCF (Damodaran's default for non-financial firms) as the course spine; equity DCF taught as the paired alternative.
- Each lesson's quiz includes one worked numeric item (Damodaran-style) to force retrieval of formulas, not just concepts.
- Capstone's core is the bias audit (anchoring/confirmation/certainty) — the through-line of Damodaran's teaching.

## Suggested next steps when user returns
- Walk through the Lesson 2 hand-calculation together; then the capstone company of their choice.
- Possible extension course: valuation of young growth companies, financial firms, or real options.
