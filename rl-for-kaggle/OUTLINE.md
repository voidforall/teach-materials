# RL for Kaggle — course outline (for authors)

10 lessons × 2 languages (EN `NNNN-slug.html`, ZH `NNNN-slug.zh.html`), plus a cheat sheet pair in `reference/`.

1. **0001-the-simulation-landscape** — Why sim competitions are different: agents play a game on a ladder, not a static test set. The toolbox: handcrafted policy / search / RL / hybrid. When RL is and isn't the right call (Santa 2020: efficient search beat deep RL). The submission-file + episode model, skill rating (TrueSkill-like), agent API (`def agent(obs, config)`), time/memory limits.
2. **0002-framing-the-mdp** — Turning a Kaggle sim into an MDP: state (what you actually observe — often only your view), action space (discrete/structured; action masking for invalid moves), episode structure, discount factor. Partial observability (POMDP) framing for games like Lux. Keystone: "the frame you choose is a modeling decision, not a given."
3. **0003-self-play-infrastructure** — kaggle-environments local runner, wrapping a sim as a Gymnasium env (reset/step contract), vectorized parallel envs, and self-play: playing current policy against itself / past snapshots. Speed matters: write your own fast simulator mirror when the official one is slow. Reproducibility of submission file (no training at submit time; pickled weights + inference-only agent).
4. **0004-reward-shaping** — Terminal-only vs shaped rewards; win/loss ±1 and its sparseness; dense shaping (score deltas, potential-based shaping to keep optimal policy invariant); reward hacks / over-shaping pathologies; multi-player (zero-sum) credit. Citations: Ng et al. 1999 potential-based shaping.
5. **0005-value-based-dqn** — Q-learning recap, DQN machinery: replay buffer, target network, epsilon-greedy; double DQN and dueling heads; action masking with Q-heads. When value-based fits: small discrete action spaces (Connect X, tic-tac-toe style). CleanRL dqn as reading.
6. **0006-policy-gradient-ppo** — REINFORCE → advantage → GAE → clipped PPO objective; entropy bonus; why PPO dominates Kaggle self-play (on-policy stability, simple). SB3 PPO on a custom env; typical hyperparameters; debugging with episode-return curves and loss sanity.
7. **0007-alphazero-recipe** — The MCTS + policy/value net recipe: PUCT selection, expansion with net priors, leaf evaluation, backup; training on self-play games with MCTS-improved visit targets; why it beats plain RL in most modern sim comps; cost caveats. AlphaZero_General as the minimal implementation lineage.
8. **0008-imitation-bootstrap** — Behavioral cloning from: the rules-based starter agents / scripted bots / top public notebooks; pretraining policy nets on expert trajectories before RL (Lux winners did exactly this); DAGGER idea; common failure: BC ceiling and distribution shift.
9. **0009-evaluation-and-leagues** — Local evaluation without overfitting the public ladder: opponent pools (past checkpoints + diverse styles), league play, Elo/TrueSkill tracking of snapshots, guarding against ladder-gaming and meta-overfit; submission cadence limits; using episode replays to debug.
10. **0010-capstone-pipeline** — Capstone: a concrete end-to-end plan for a small sim (Connect X): gym wrapper → DQN or AlphaZero-lite self-play → eval vs pool → package `submission.py`. Checklist of Kaggle pitfalls: timeouts per turn, validation errors, deterministic seeds, file size, no network at inference.

Reference: **rl-kaggle-cheatsheet** (EN+ZH) — one printable page: decision table (which method when), DQN/PPO/AlphaZero mini-pseudocode, reward shaping rules, self-play checklist, submission checklist, glossary.
