Capstone Pipeline

Everything in one place: wrap Connect X as a Gym env, train an agent with self-play, evaluate against a pool, and ship a submission file that survives validation.

This is the whole course assembled into a build plan you can run this week on Connect X — small enough to finish, real enough to generalize. Every stage cites the lesson that taught it.

Stage 1 — The environment (Lesson 3)

Wrap the kaggle-environments local runner as a Gymnasium env: reset() returns the observed board, step(action) advances both players (opponent from the pool), and rewards follow Lesson 4's shaping. Stage 2 — The learner (Lessons 5–7)

Pick by action-space size and time budget: DQN (CleanRL dqn.py — 7 actions, masked Q-heads) is the one-weekend option; AlphaZero-lite (AlphaZero_General lineage — PUCT search + policy/value net on visit targets) is the medal-grade option and the better teacher of the material. Optional per Lesson 8: clone negamax first as a warm start. Self-play against the snapshot pool from step one — never against only the latest policy.

Stage 3 — The league (Lesson 9)

Nightly: candidates vs pool (snapshots + negamax + your scripted bot), 200 games each, both seats, TrueSkill table. Promote only on CI-clear wins. This table is your experiment log — every training decision should be justifiable by a row in it.

Stage 4 — The submission file (Lessons 1, 3)

The submission is a single submission.py: inference only, no training, no network. Weights are baked in — pickled into the file or attached as a Kaggle dataset next to it.

# submission.py — the entire agent
import pickle
weights = pickle.loads(b"...")   # or np.load from attached dataset
net = load_net(weights)          # construct at import time, not per turn

def agent(obs, config):
    board = encode(obs, config)          # same planes as training!
    return int(net.act(board, mask=legal(obs)))

The Kaggle pitfalls checklist

  • Per-turn timeouts: first turn and every turn after have separate budgets (Connect X: seconds, not minutes). Measure worst-case inference time, not average; construct networks at import, never inside agent().
  • Validation pass: submit early with a trivial agent to burn in the pipeline; errors here are formatting, not intelligence.
  • No training at submit time: the file must be deterministic inference; any "learn during the episode" trick must fit in turn budgets and rules.
  • Deterministic seeds: fix seeds for reproducibility, but verify the agent works when the harness seeds differently.
  • File size: check the cap (often ~100 KB for inline files or 20 MB with utility scripts/datasets) — compress or quantize weights if needed.
  • Offline at inference: no network access; all dependencies vendored or attached.
Keystone A Kaggle agent is a delivery problem as much as a learning problem.The best policy that times out, fails validation, or drifts from its training encoding scores exactly zero. Ship the pipeline end-to-end in week one, then improve in a loop.
Anti-pattern Submitting the research notebook as the agent.The training script builds datasets, spawns environments, and downloads models — none of which exists in the grading sandbox. The submission is one file, import-time loading, per-turn inference, and nothing else.

Retrieve it

Why must the network be constructed at import time in submission.py?

Construction costs a whole turn.

Building the model inside agent() charges setup time to a single turn's budget, risking an instant timeout. Import-time setup pays once, before the clock starts.

Why evaluate candidates against a pool instead of the previous best only?

One opponent hides blind spots.

Beating the latest snapshot is necessary but not sufficient — hard-counter styles in a diverse pool expose regressions that head-to-head play conceals. League rows are the evidence.

What encoding bug silently ruins a submission?

Inference mismatching training.

If the submission encodes the board differently than during training (plane order, perspective, masking), the net receives out-of-distribution inputs and plays garbage — while passing validation happily.

Prove it to yourself

Do it — the actual capstone Build the pipeline: gym wrapper → DQN or AlphaZero-lite self-play → league table vs negamax and snapshots → submission.py. Submit to Connect X. Then compare your local league win-rate to your actual Kaggle skill rating after ~50 episodes — that gap is your measurement of how well you evaluate. Start from kaggle-environments and the CleanRL single-file implementations.
