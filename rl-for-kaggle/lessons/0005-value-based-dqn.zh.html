基于价值的方法：DQN

Q-learning 学的是一张"在这个状态下走这步有多好"的表格，然后取 argmax。DQN 就是把这张表格换成神经网络——再加上两个防止它自我吞噬的机制。

基于价值的方法从不直接碰策略。它学习 Q(s, a)——在状态 s 执行动作 a、之后始终最优行动所能获得的期望折扣回报——策略由 argmaxa Q(s, a) 推出。更新公式是 Bellman 回溯：

r + γ · max<sub>a'</sub> Q(s', a')  −  Q(s, a)   →  损失（TD 误差）

用网络来近似 Q 之后，这个自举过程就不稳定了：目标值本身由这个网络计算，所以一直在动。DQN 原论文（Mnih 等，2015）用两个机制稳住了它，而在任何竞赛实现里，这两者都不可省略：

  • 经验回放池（replay buffer）——存下转移样本，随机抽取小批量。它打破了自博弈轨迹在时间上的相关性，还让每一步昂贵的仿真被复用多次。
  • 目标网络（target network）——用一个冻结的 Q 副本来计算目标值，每 N 步同步一次。"追自己"的病态变成了"追一个缓慢移动的副本"，这就收敛了。

两个标准升级负责消除剩余偏差。Double DQN（van Hasselt 等，2015）把选动作和估值解耦：在线网络选出 argmax 动作，目标网络来打分——从而消除 max 带来的系统性高估。Dueling 双头（Wang 等，2015）把 Q 拆成 V(s) + A(s,a)，这样"每个动作价值都相同"的状态就不会产生噪声导致的虚假动作偏好——在许多回合属于强制着法的 Kaggle 仿真里很有用。

Kaggle 式动作屏蔽

仿真环境会拒绝非法动作（更糟的是白白浪费你的回合）。不要让网络去"学会"合法性——在 argmax 之前做屏蔽：

q = qnet(s)                      # 形状 [n_actions]
q[~valid_action_mask(s)] = -inf  # 或 -1e9
a = argmax(q)                    # 贪心；ε-greedy 也只在合法集合上探索

它与 dueling 双头组合良好，也是新手 DQN 提交里最常见的 bug 来源：一个只能在 Connect X 的 7 列中选择的智能体，argmax 里永远不该出现第 8 列（或已满的列）。

关键点 DQN = Q-learning + 经验回放 + 目标网络；其余都是偏差修正。当你的价值型智能体发散时，先检查这两个稳定器，再动超参数——并且要在 argmax 之前屏蔽非法动作，而不是等环境拒绝之后补救。
反面模式 每一步都同步目标网络（或忘写经验回放）。目标不停移动，TD 误差永远无法稳定——损失震荡、Q 值膨胀、智能体塌缩成只会走一个动作。典型症状：Q 值飘到远超任何合理回报的范围；ε-greedy 智能体既不探索也不再赢棋。

回忆检索

DQN 为什么必须要经验回放池——没有它会坏什么？

样本相关且无法复用。

自博弈的相邻转移高度相关，违反 SGD 的 i.i.d. 假设，并导致灾难性遗忘。从回放池随机采样可以给批量去相关，并让每一步仿真被复用多次——在每一步都很贵时尤为关键。

Double DQN 消除的是哪种具体偏差？

max-Q 的高估。

maxa Q(s', a) 用同一组带噪的值既做选择又做打分，噪声会把目标系统性推高。把选择（在线网络）与评估（目标网络）解耦，几乎不改结构就能消掉大部分偏差。

你的仿真这一回合有 7 个合法动作，下一回合有 3 个。合法性应该在流程的哪一环介入？

在 argmax 之前屏蔽 Q 值。

把非法项设为 −∞（或很大的负数），贪心选择和 ε-greedy 探索就都只在合法集合上进行。让网络靠惩罚信号"学会"合法性，既浪费容量又 destabilize 训练。

亲手验证

试一试 —— 20–30 分钟，读真实代码 打开 CleanRL 的单文件实现：docs.cleanrl.dev — dqn.py。找到并做注释：(1) 回放池的写入与采样调用；(2) 目标网络同步（target.load_state_dict）；(3) TD 损失那一行——注意它用的是普通 max，不是 Double DQN。然后动手修改：用 3 行实现 Double DQN，并加一个动作屏蔽钩子（一个接收观测、返回有效性掩码的函数，在 argmax 之前作用于 q_values）。数学不稳的话，对照 Spinning Up 的 Q-learning 部分。
