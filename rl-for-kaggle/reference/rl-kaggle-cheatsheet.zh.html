RL for Kaggle — 速查表

十课内容压缩成一页可打印的速查表：何种情形用何种技术、核心更新公式、奖励塑形纪律、自博弈与提交清单、术语表。从第 1 课开始。

1 · 何种情形用何种技术

技术适用情形注意事项
手写策略规则已知；时间预算紧；需要可击败的基线硬天花板；它是你的 BC 老师，不是你的智能体
树搜索（minimax/negamax）博弈树小、模拟廉价（Santa 类谜题、Connect X）分支数 × 深度 = 时钟时间；需要好的评估函数
DQN小的离散动作空间；单网络 + 经验回放的简洁性离策略不稳；超大/结构化掩码动作表现差
PPO自博弈循环、结构化动作；要简单稳健在策略 = 吃数据；熵奖励太小会策略塌缩
AlphaZero 式任何能快速镜像的模拟赛冲奖牌；策略+价值+MCTS算力开销大；瓶颈是模拟速度，自己写快仿真
模仿引导只要存在脚本专家就用——RL 前的热启动BC 天花板与分布偏移；专家数据要退火掉

2 · 核心更新公式

DQN 目标：      y = r + γ · Q_target(s', argmax_a Q_online(s',a))   # 双重 DQN
PPO 目标：      L = E[ min(ρ·A, clip(ρ, 1−ε, 1+ε)·A) ]  其中 ρ = π(a|s)/π_old(a|s)
MCTS（PUCT）：  argmax_a Q(s,a) + c_puct · P(s,a)·√ΣN / (1+N(s,a))
  • DQN 全家桶：经验回放、目标网络（慢同步）、ε-贪心、动作掩码 Q 头。
  • PPO 附加件：GAE(λ) 优势、熵奖励、价值函数损失、每批仅跑几个 epoch。
  • AlphaZero：策略以 MCTS 访问计数（改进目标）训练，价值以对局结果训练。

3 · 奖励塑形经验法则

  • 终局胜负 ±1 是唯一不可谈判的项——它就是排行榜指标。
  • 优先用基于势函数的塑形：r' = r + γΦ(s') − Φ(s)——可证不改变最优策略。
  • 启发式塑形（分数增量、生存奖励）：小、可监控、随胜率上升衰减到零。
  • 警报：塑形奖励上涨而真实胜率停滞、回合拉长 = 奖励被钻空子。

4 · 自博弈清单

  • 每 N 个存档点快照进对手池——绝不只对最新策略训练。
  • 混风格：快照 + 脚本机器人 + 官方示例（规则允许时加公开机器人）。
  • 快速仿真：封装成 Gymnasium 环境；官方运行器慢就自己写镜像。
  • 非对称博弈换边；固定种子；并行向量化环境。
  • 只有联赛证据支持才晋升快照，不是一个头对头胜率。

5 · 提交清单

  • 每回合时间预算达标——测最坏情况推理耗时，不是平均值。
  • 网络在 import 时构建；绝不放进 agent(obs, config) 里。
  • 先用平凡智能体通过 Kaggle 校验（先跑通流水线再谈智力）。
  • 纯推理：权重离线烘入，提交时不训练、不联网。
  • 确定性种子——且评测方换种子时依然正确。
  • 文件大小低于上限（内联约 100 KB / 附文件约 20 MB）；必要时量化权重。
  • 推理编码与训练完全一致（平面、视角、掩码）。

6 · 术语表

MDP马尔可夫决策过程：(状态, 动作, 奖励, 转移)——你强加给模拟赛的框架。
POMDP部分可观测 MDP：只看到自己的视角（Lux）；用记忆/循环网络或信念搜索。
自博弈智能体对自己或自己的历史版本训练——生成无限对手。
快照池冻结的历史存档点，用作训练对手与评估基准。
联赛种群内全员互赛并用 Elo/TrueSkill 评分；AlphaStar 的微缩版。
GAE广义优势估计：用 λ 混合 TD 残差，得到低方差的优势。
PUCTPredictor + UCT：MCTS 选择规则，在价值、先验、访问计数间权衡。
行为克隆对专家动作做监督式模仿；热启动，但有硬天花板。
Elo / TrueSkill由胜负估计成对技能评分；TrueSkill 带不确定度（σ）——Kaggle 天梯即此类。
