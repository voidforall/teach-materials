# Resources — LLM security

## Canonical / high-trust
- OWASP Top 10 for LLM Applications (2025) — https://genai.owasp.org/llm-top-10/ — the standard taxonomy: prompt injection, sensitive info disclosure, excessive agency, etc.
- Simon Willison, "Prompt injection" series — https://simonwillison.net/series/prompt-injection/ — the clearest practitioner treatment; coined the term (2022).
- Greshake et al., "Not what you've signed up for: Compromising Real-World LLM-integrated Applications with Indirect Prompt Injection" (2023) — https://arxiv.org/abs/2302.12173 — the indirect injection paper.
- Perez & Ribeiro, "Ignore Previous Prompt: System Processing Scope Attacks" (2022) — https://arxiv.org/abs/2211.09527.
- Zou et al., GCG adversarial suffix attacks — https://arxiv.org/abs/2307.15043.
- Anthropic, "Many-shot Jailbreaking" (2024) — https://www.anthropic.com/research/many-shot-jailbreaking.
- Wei et al., "Jailbroken: How Does LLM Safety Training Fail?" (2023) — https://arxiv.org/abs/2307.02475 — taxonomy of jailbreak mechanisms (competing objectives, mismatched generalization).
- Microsoft, "Failure modes in autonomous agents" & spotlighting defenses (Hines et al. 2024) — https://arxiv.org/abs/2403.07575.
- LlamaIndex/agent security: "AgentDojo" benchmark (NeMo, Debenedetti et al.) — https://agentdojo.spylab.ethz.ch/ — prompt-injection agent benchmark with attack success vs robustness trade-offs.
- CrowdStrike press release: International AI Security Challenge — https://www.crowdstrike.com/en-us/press-releases/crowdstrike-announces-international-ai-security-challenge/
- HackAPrompt / Gandalf (Lakera) — practical prompt-hacking playgrounds — https://gandalf.lakera.ai/
- NIST AI 100-2e2025 "Adversarial Machine Learning: A Taxonomy of Attacks" — https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-2e2025.pdf
