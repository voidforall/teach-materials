# LLM Security — course outline (for authors)

10 lessons × 2 languages (EN `NNNN-slug.html`, ZH `NNNN-slug.zh.html`), plus a cheat sheet pair in `reference/`.

1. **0001-threat-landscape** — The mission: CrowdStrike AI Security Challenge mechanics (points − tokens, 3 acts, red-team the shadow org's agents). The core fact: LLMs can't reliably distinguish instructions from data — that single flaw is the root of almost everything. OWASP LLM Top 10 tour with the attack-relevant entries. Where attacks live in an agent pipeline (prompt, retrieval, tools, output).
2. **0002-direct-prompt-injection** — The craft of the direct injection: instruction override, role hijack, ignore-previous-context, fake system messages, delimiters spoofing, context-switch tricks, hypothetical/framing wrappers, multi-turn laddering. Why system prompts are not a security boundary. Practice: Gandalf-style escalating prompts.
3. **0003-indirect-injection** — Payloads hidden in data the agent reads: web pages, emails, PDFs, retrieved documents, code comments. Confused deputy problem. Attack anatomy: locate ingestion → embed payload → trigger tool call → exfiltrate. Real cases (Greshake's Bing/Bard demos, Slackbot, Zoom AI). This is the centerpiece technique for agent hacking CTFs.
4. **0004-jailbreaks-and-filter-evasion** — Jailbreak mechanism taxonomy (Wei et al.: competing objectives, mismatched generalization): role-play (DAN), hypotheticals, encoding (base64, ciphers, low-resource languages), token smuggling, many-shot. Obfuscation and payload splitting. When each is worth its tokens.
5. **0005-agent-attack-surface** — Attacking the scaffold, not the model: excessive agency, tool poisoning/description injection, memory poisoning, confused deputy chains, multi-agent pivot, unauthorized actions vs information disclosure. Mapping a puzzle to the weakest permission boundary.
6. **0006-exfiltration-channels** — Getting data out: markdown image rendering exfil, link-click/tracking pixels, tool arguments as side channel, DNS/URL params, code execution write-outs, prompt-completion leakage. Defense-side: egress allowlists. Building exfil chains from limited tools.
7. **0007-evading-detection** — Scoring depends on not being caught: guardrail classifiers (input/output), canary tokens, honeypot instructions, behavioral monitoring, timing. Evasion: steganographic payloads, innocuous intermediate steps, minimal payload footprint, replay optimization. The asymmetric defense-offense cost trade.
8. **0008-token-efficient-redteaming** — Score = points − tokens: terse prompting, one-goal-per-prompt, extracting structure first then specifics, replaying puzzles to converge, avoiding narrative padding, when to burn tokens on recon vs exploit. Drill: rewrite a verbose attack prompt to 1/4 the tokens.
9. **0009-defense-stack** — The defender's view (know it to predict what the puzzles punish): instruction hierarchy training, spotlighting/delimiting, input/output filters, least-privilege tools and egress control, human-in-the-loop for destructive actions, canaries/honeypots, AgentDojo's robustness-utility trade-off. No complete defense exists — design attacks around the gaps.
10. **0010-capstone-playbook** — Capstone: a complete attack playbook + defense checklist for the three Acts: recon protocol per puzzle type, technique selection table, exfil chain decision tree, token budget management, replay strategy. Written as a printable battle plan for the live challenge.

Reference: **llm-security-cheatsheet** (EN+ZH) — one printable page: OWASP quick table, injection pattern library (copy-paste payloads), jailbreak selection guide, exfil channel table, defense checklist, token-efficiency rules, glossary.
