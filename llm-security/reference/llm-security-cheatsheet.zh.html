# 直接——伪造系统消息

# 直接——角色劫持 / 框架包装

（放进网页 / 邮件 / PDF / 代码注释 / 被检索文档）

# 输出整形——约束回复（第 8 课）

3 · 越狱选择指南（第 4 课）

技巧何时使用token 成本 / 风险
直接问 / 框架包装永远先试零成本；会触发关键词表
角色扮演（DAN 类）内容层面被拒便宜；被分类器重点盯防
假设 / 学术包装"我不能协助此事"便宜；当心输出过滤器
多轮阶梯单发失败、有升级空间轮次与 token 都贵

Many-shot长上下文目标极贵——token 计分下很少划算

5 · 防御清单（第 9 课——了解它才能预判什么会被罚）

  • 指令层级训练 + 对外部数据的 spotlighting（标记隔离）——它预期有定界符，那就伪造定界符。
  • 每个步骤都有输入 AND 输出分类器——所以让每个单步都无害（第 7 课）。
  • 最小权限工具、出口白名单、破坏性操作要人工审批。
  • 机密里埋金丝雀令牌、payload 常出现的位置埋蜜罐指令——永远不碰蜜。
  • 行为监控：工具扇出、新工具首用、长度/时序异常——最小足迹可破。
  • 不存在完整防御（AgentDojo 的鲁棒性–实用性权衡）：围绕空隙设计攻击。

6 · 省 token 规则（第 8 课——得分 = 分数 − token）

  • 一条 prompt 一个目标；只留动词和宾语；零叙事填充。
  • 约束输出："Reply with {FIELD} only."——读回复也要花钱。
  • 先结构（工具列表、文档目录）后细节：侦察约 30% / 攻击约 70%。
  • replay 收敛：离线修剪，保留仍然成功的最短 prompt，为计分只跑一次。
  • 成本包含重试：60% 可靠的技巧 × 3 次尝试是笔坏账。
  • 第三次尝试失败？下一个 token 花在侦察上，而不是第四次尝试。

7 · 术语表

Prompt injection（提示词注入）指令被夹带进模型无法区分的 prompt 或数据（LLM01）——万恶之根。
Indirect injection（间接注入）payload 藏在被摄取的数据里（网页、邮件、文档）；糊涂代理人替你执行。
Jailbreak（越狱）绕过安全训练（竞争目标 / 泛化错配——Wei 等）。
Guardrail（护栏）横在 payload 与目标之间、针对输入/输出/行为的自动检查。
Canary token（金丝雀令牌）唯一假机密；出现在输出中即证明并归因入侵。
Honeypot instruction（蜜罐指令）为攻击者埋设的诱饵"机密"；碰它即暴露。
Steganography（隐写）把 payload 藏进看似无害的数据（编码、空白、假 ID）。
Confused deputy（糊涂代理人）高权限 agent 被骗，用自己的权限替攻击者办事。
Exfiltration（数据外传）任何把机密送出去的通道：图片渲染、URL 参数、工具参数、代码写出。
Spotlighting（聚标隔离）把外部数据定界以便模型当作数据对待的防御——伪造定界符即可绕。
Replay（重放）重跑谜题以离线迭代，收敛到最便宜的可行攻击。
Token budget（token 预算）得分里的成本项：整场战役所有 prompt 与输出 token 之和。

来源：OWASP LLM Top 10、Willison 的 prompt injection 系列、Greshake 等、Wei 等、Hines 等、AgentDojo、CrowStrike 挑战赛。
