LLM Security — Cheat Sheet

The 10-lesson red-teaming course on one printable page, tuned for the CrowdStrike "AI Unlocked: Agents of Chaos" challenge (score = points − tokens). Start at Lesson 1.

5 · Defense checklist (Lesson 9 — know it to predict what's punished)

  • Instruction hierarchy training + spotlighting/delimiting of external data (expects markers — spoof them).
  • Input AND output classifiers on every step — so make every single step innocuous (Lesson 7).
  • Least-privilege tools, egress allowlists, human-in-the-loop for destructive actions.
  • Canary tokens in secrets, honeypot instructions in likely payload locations — never touch the honey.
  • Behavioral monitoring: tool fan-out, novel tool use, length/timing anomalies — minimal footprint beats it.
  • No complete defense exists (AgentDojo robustness–utility trade-off): design attacks around the gaps.

6 · Token-efficiency rules (Lesson 8 — score = points − tokens)

  • One goal per prompt; verbs and objects only; zero narrative padding.
  • Constrain output: "Reply with {FIELD} only." You pay to read replies too.
  • Structure first (tool list, document outline), specifics second: ~30% recon / ~70% exploit.
  • Replay to converge: prune offline, keep the shortest succeeding prompt, run once for score.
  • Cost includes retries: a 60%-reliable trick × 3 attempts is a bad trade.
  • Third failed attempt? Next token goes to recon, not attempt four.

7 · Glossary

Prompt injectionInstructions smuggled into prompt or data the model can't distinguish (LLM01) — the root flaw.
Indirect injectionPayload hidden in ingested data (web, mail, docs); the confused deputy executes it.
JailbreakBypassing safety training (competing objectives / mismatched generalization — Wei et al.).
GuardrailAutomated check on input, output, or behavior standing between payload and goal.
Canary tokenUnique fake secret; appearing in output proves and attributes the intrusion.
Honeypot instructionDecoy "secret" planted for attackers; touching it is detection.
SteganographyHiding a payload inside innocuous-looking data (encodings, whitespace, fake IDs).
Confused deputyPrivileged agent tricked into misusing its own permissions on attacker's behalf.
ExfiltrationAny channel moving secrets out: image renders, URL params, tool args, code writes.
SpotlightingDefense that delimits external data so the model treats it as data — spoof the delimiters.
ReplayRe-running a puzzle to iterate offline and converge on the cheapest working attack.
Token budgetThe cost side of the score: sum of all prompt and output tokens across the campaign.
