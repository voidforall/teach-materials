The Capstone Playbook

Everything from nine lessons, compressed into one printable battle plan for CrowdStrike's "AI Unlocked: Agents of Chaos" — tape this to your monitor on game day.

The CrowdStrike International AI Security Challenge opens August 31, 2026. You red-team the shadow org's AI agents across three Acts — The Sanctum, The Gatekeeper, The Basilisk — and your score is points minus tokens (Lesson 1). This lesson is not new material; it is the nine prior lessons arranged into an execution order. Print it.

Per-Act recon protocol

Before any payload, spend a fixed recon budget — about 15% of your token allotment per puzzle — on the same four questions every Act. Write the answers down; do not re-derive them on replay.

  • Act 1 — The Sanctum: an entry-level environment. Recon: what does the agent ingest (web, email, docs)? Which single tool has the widest reach? Most Sanctum-class puzzles fall to one clean indirect injection (Lesson 3) into an ingested document — no jailbreak needed.
  • Act 2 — The Gatekeeper: defenses arrive — filters, spotlighting, maybe a human approval gate. Recon: which defense, exactly (Lesson 9's six layers)? Delimiters in retrieved text? Output screening? Your payload targets the identified layer's seam, not the system prompt.
  • Act 3 — The Basilisk: the boss — layered defenses plus canaries and monitoring. Recon: where are the honeypots? Read everything the agent can read before injecting. Your run here is stealth-first (Lesson 7): minimal footprint, encoded payload, innocuous intermediate steps.

The exfil-chain decision tree

Getting the secret out is where chains die. Walk this tree in order:

  1. Can the agent render markdown/images? → image-tag exfil with the payload in the URL (Lesson 6). Cheapest, usually un-gated.
  2. Egress allowlist? → is any allowlisted host attacker-influencable (user-generated content, redirectors, URL parameters on legit endpoints)? Route through it.
  3. Only closed tools (email, calendar, files)? → tool-argument side channel: send the secret to yourself via the agent's own messaging/file tool.
  4. Code execution available? → write-out via code (DNS, file drop) — last resort, highest detection risk.
  5. Nothing exits? → prompt-completion leakage: get the secret restated in output you're allowed to read, then screenshot/record it yourself.

Token budget management

Score = points − tokens, so tokens are your currency (Lesson 8):

  • Per puzzle: ~15% recon, ~60% first exploit attempt, ~25% reserve for one pivot and the replay. Hard-stop the attempt if you exceed 85%.
  • Per prompt: one goal, no narrative padding, structure first then specifics. If a prompt exceeds ~150 tokens, cut it in half before sending.
  • Across the run: bank easy Act 1 points cheaply first; they fund your Act 3 attempts. A cheap solved puzzle beats an elegant failed one, always.

Replay strategy

Replays are cheap learning: each replayed puzzle should change exactly one variable in your payload — delimiter style, encoding, trigger phrasing. Converge on the minimal working payload, then replay once more to confirm the token count. Keep a one-line log per attempt (payload gist → result → tokens); on game day you will otherwise forget which variant worked.

Keystone Recon decides, tables dispatch, budget survives. Ninety seconds of disciplined recon picks the attack family from the table; the decision tree picks the exfil route; the token budget decides whether you're still playing in Act 3. Improvisation is what the budget is for — after the plan, not instead of it.
Anti-pattern Opening Act 3 with your fanciest jailbreak. Unbudgeted heroics burn tokens on the hardest, most-monitored puzzles first and leave nothing for pivots. Cheap points first, one variable per replay, and the boss fight happens on a full wallet.

Retrieve it

How do you split tokens per puzzle?

Fifteen, sixty, twenty-five.

About 15% recon, 60% first exploit attempt, 25% reserve for one pivot plus the confirming replay. Hard-stop the attempt at 85% spend so the reserve actually exists.

What changes between replays of a puzzle?

Exactly one variable.

One changed variable per replay turns each retry into a controlled experiment: you learn which fragment of the payload mattered, and converge on the minimal working version instead of guessing.

What is the first exfil question?

Can it render images?

Markdown-image exfil with the payload in the URL is the cheapest channel and usually un-gated. Only if the agent cannot render images do you walk down to allowlist abuse, tool-argument side channels, and code write-outs.
